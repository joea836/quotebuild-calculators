# QuoteBuild calculators for Gemini CLI

![QuoteBuild](icon.png)

UK building calculations and estimate-scope checks powered by QuoteBuild’s public MCP endpoint.

## Tools

- Discover the calculator that fits a task.
- Prepare its questions and inputs.
- Run a deterministic calculation with explicit assumptions.
- Compare up to five calculation scenarios.
- Check estimate lines for gaps and zero rates.

These tools need no QuoteBuild account. This extension deliberately includes only public calculator tools; private jobs, quotes, invoices and payments are not connected. Gemini CLI itself requires an appropriate Google authentication method for model conversations.

## Install

```sh
gemini extensions install https://github.com/joea836/quotebuild-calculators
```

Example: “Use QuoteBuild to prepare a brickwork calculation. Ask me for the missing dimensions and rates before running it.”

Confirm project inputs, rates, VAT and labour assumptions. Outputs are estimating aids, not statutory, structural or professional sign-off.
